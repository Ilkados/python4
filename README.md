# File and stream exercises

Five exercises explore reading text, writing archives, managing streams, and handling file errors. This version includes sample output files under `ex1` and `ex3`.

## Try the first example

From the repository root, use Python 3.10 or newer.

```sh
python3 ex0/ft_ancient_text.py
```

The script looks for `ancient_fragment.txt` in the current directory. With no file present it demonstrates the missing-file handler. To try the successful read, place a text file with that name in the same directory and run the command again.

Read the [example source](ex0/ft_ancient_text.py).
